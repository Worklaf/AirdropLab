# 🚀 Установка и настройка проекта

## 📋 Обязательные шаги после клонирования:

### 1. Настройка Firebase
Скопируйте шаблон конфигурации и вставьте свои данные:
```bash
cp config.js.example config.js
```

Откройте `config.js` и замените `YOUR_*` значения на ваши реальные данные из Firebase консоли.

### 2. Настройка переменных окружения
Скопируйте шаблон .env файла:
```bash
cp .env.example .env
```

Откройте `.env` и вставьте ваши реальные значения.

### 3. ⚠️ ВАЖНО - Безопасность
- **НИКОГДА** не коммитьте `config.js` и `.env` в Git!
- Эти файлы уже добавлены в `.gitignore`
- Только `config.js.example` и `.env.example` должны быть в репозитории

### 4. Запуск проекта
Откройте `index.html` в браузере или запустите локальный сервер.

## 🔒 Где взять данные Firebase?
1. Зайдите в [Firebase Console](https://console.firebase.google.com)
2. Выберите ваш проект
3. Настройки проекта → Общие → Ваши приложения
4. Скопируйте конфигурацию в `config.js`

## 🛠️ Для разработчиков
При деплое на продакшен используйте environment переменные хостинга вместо файлов конфигурации.
