# 🚀 План разработки чата AirdropLab

## 📋 Обзор проекта

Создание полнофункционального чата для сообщества AirdropLab с продвинутыми функциями модерации, геймификации и мультиязычной поддержкой.

## 🎯 Финальный функционал чата

### 📋 Основные функции:
- ✅ **Авторизация только для зарегистрированных**
- 📝 **Правила чата** - обязательны к прочтению
- 🛡️ **Модерация** - бан/мут/удаление сообщений
- 🔗 **Фильтр ссылок** - проверка на вредоносность
- 🚫 **Антиспам** - защита от флуда и рекламы
- 📊 **Репорты** - пользователи могут жаловаться
- 👥 **Онлайн-статус** - кто сейчас в сети

### 💬 Каналы чата (как в Discord):
- 🌍 **Общий** - main канал для всех
- 💬 **Оффтоп** - разговоры на свободные темы
- 📢 **Анонсы** - важные сообщения от админов
- 🆘 **Помощь** - техническая поддержка
- 💡 **Идеи** - предложения по улучшению

### 🛡️ Система безопасности:

## 📋 Требования к безопасности

### Firebase Security Rules:
```json
{
  "rules": {
    "chat": {
      "$channel": {
        ".read": "auth != null",
        ".write": "auth != null && 
          (root.child('chat').child('users').child(auth.uid).child('role').val() !== 'banned')",
        "messages": {
          "$message": {
            ".validate": "newData.child('uid').val() === auth.uid &&
                        newData.child('timestamp').val() === now &&
                        newData.child('message').val().length <= 1000"
          }
        }
      },
      "users": {
        "$uid": {
          ".read": "$uid === auth.uid || 
                   root.child('chat').child('users').child(auth.uid).child('role').val() === 'admin'",
          ".write": "$uid === auth.uid || 
                   root.child('chat').child('users').child(auth.uid).child('role').val() === 'admin'"
        }
      },
      "moderation": {
        ".read": "root.child('chat').child('users').child(auth.uid).child('role').val() in ['admin', 'moderator']",
        ".write": "root.child('chat').child('users').child(auth.uid).child('role').val() in ['admin', 'moderator']"
      }
    }
  }
}
```
