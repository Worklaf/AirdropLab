Translation Consistency Checker

HTML‑страница с полной инструкцией и единым скриптом для проверки консистентности переводов (RU / ES / TR / EN). Скопируйте содержимое блока <script> и выполните в консоли браузера после вставки объекта translations.

Кратко

  • Проверяет количество ключей в каждом языке.
  • Находит ключи, которые есть в ru, но отсутствуют в es, tr, en.
  • Находит лишние ключи в переводах (есть в переводе, но нет в ru).
  • Выводит русские значения для пропущенных ключей — удобно копировать для перевода.
  • Безопасно обрабатывает отсутствие английского блока (en может быть пустым).

Важное предупреждение

Перед запуском: в консоли должен быть определён полный объект translations. Если вставить только часть — появится ошибка ReferenceError: translations is not defined.

Подготовка

Откройте DevTools → Console и вставьте ваш объект переводов целиком. Пример структуры (замените комментарии реальными данными):

// Пример: вставьте ваш реальный объект translations целиком
const translations = {
  ru: {
    /* все ключи и значения на русском */
  },
  es: {
    /* все ключи и значения на испанском */
  },
  tr: {
    /* все ключи и значения на турецком */
  },
  en: {
    /* все ключи и значения на английском или {} если нет */
  }
};

Единый скрипт проверки

Скопируйте и выполните этот блок после того, как вставили объект translations в консоль.

// === Translation Consistency Checker (выполнить в консоли) ===

// 1) Собираем ключи (безопасно обрабатываем отсутствие en)
const ruKeys = Object.keys(translations.ru || {});
const esKeys = Object.keys(translations.es || {});
const trKeys = Object.keys(translations.tr || {});
const enKeys = Object.keys(translations.en || {});

// 2) Количество ключей
console.log("RU keys:", ruKeys.length);
console.log("ES keys:", esKeys.length);
console.log("TR keys:", trKeys.length);
console.log("EN keys:", enKeys.length);

// 3) Пропущенные ключи (есть в RU, но нет в переводах)
const missingInEs = ruKeys.filter(k => !esKeys.includes(k));
const missingInTr = ruKeys.filter(k => !trKeys.includes(k));
const missingInEn = ruKeys.filter(k => !enKeys.includes(k));

console.log("❌ Отсутствуют в ES:", missingInEs);
console.log("❌ Отсутствуют в TR:", missingInTr);
console.log("❌ Отсутствуют в EN:", missingInEn);

// 4) Лишние ключи (есть в переводах, но нет в RU)
const extraInEs = esKeys.filter(k => !ruKeys.includes(k));
const extraInTr = trKeys.filter(k => !ruKeys.includes(k));
const extraInEn = enKeys.filter(k => !ruKeys.includes(k));

console.log("⚠️ Лишние в ES:", extraInEs);
console.log("⚠️ Лишние в TR:", extraInTr);
console.log("⚠️ Лишние в EN:", extraInEn);

// 5) Вывод русских значений для пропущенных ключей (удобно копировать для перевода)
console.log("=== RU → ES: пропущенные строки ===");
missingInEs.forEach(k => console.log(`${k}:`, translations.ru[k]));

console.log("=== RU → TR: пропущенные строки ===");
missingInTr.forEach(k => console.log(`${k}:`, translations.ru[k]));

console.log("=== RU → EN: пропущенные строки ===");
missingInEn.forEach(k => console.log(`${k}:`, translations.ru[k]));

// 6) Компактный свод в виде объекта (если нужно скопировать в файл)
const report = {
  counts: { ru: ruKeys.length, es: esKeys.length, tr: trKeys.length, en: enKeys.length },
  missing: { es: missingInEs, tr: missingInTr, en: missingInEn },
  extra: { es: extraInEs, tr: extraInTr, en: extraInEn }
};
console.log("=== Summary object ===");
console.log(report);

// === Конец скрипта ===

Как читать результаты

  • RU keys — эталонное количество ключей в русском блоке.
  • Отсутствуют в ES/TR/EN — ключи, которые есть в ru, но отсутствуют в переводе; их нужно перевести.
  • Лишние в ES/TR/EN — ключи, которые есть в переводе, но отсутствуют в ru; возможно устаревшие или ошибочные.
  • RU → ... — выводит пары ключ: русская строка для всех пропущенных ключей; удобно копировать и переводить.

Пошаговая инструкция

  1. Откройте файл переводов (например, languages.js или translations.js).
  2. Откройте браузер → DevTools → Console.
  3. Скопируйте и вставьте в консоль весь объект translations (см. раздел «Подготовка»), нажмите Enter.
  4. Скопируйте и выполните блок «Единый скрипт проверки».
  5. Проанализируйте вывод: сначала — количества, затем — списки «Отсутствуют» и «Лишние», затем — секции «RU → ...».
  6. Внесите переводы в соответствующие блоки es, tr, en и повторите проверку.

Частые ошибки и решения

ReferenceError: translations is not defined
Причина: в консоли не определён объект translations (вставлен не весь объект).
Решение: вставьте весь объект translations целиком и затем выполните скрипт.
Синтаксические ошибки при вставке объекта
Убедитесь, что объект корректен с точки зрения JavaScript: закрытые кавычки, запятые, отсутствие комментариев в JSON‑стиле. Если используете JSON, удалите JS‑комментарии.

Рекомендации и лучшие практики

  • Храните translation-check.md рядом с файлом переводов в репозитории.
  • Перед коммитом переводов запускайте этот скрипт, чтобы убедиться в синхронизации ключей.
  • При добавлении новых ключей в ru — добавляйте заглушки в es и tr (например пустые строки), чтобы не накапливать большой список пропусков.
  • Для автоматизации можно создать Node.js‑скрипт или GitHub Action; при желании — могу помочь с этим.
